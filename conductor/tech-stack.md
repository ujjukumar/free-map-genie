# Technology Stack - FMG: Free Mapgenie PRO!

## Core Technologies
- **Programming Language:** [TypeScript](https://www.typescriptlang.org/) - Provides static typing and modern JavaScript features for robust extension development.
- **Frontend Framework:** [React](https://reactjs.org/) - Powering the extension's popup UI and complex interactive components.
- **Extension API:** [WebExtensions API](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions) - Cross-browser standard for extension development, ensuring compatibility with Chrome, Firefox, and Edge.

## Build and Development Tools
- **Bundler:** [Webpack](https://webpack.js.org/) - Handles module bundling, asset management, and environment-specific configurations.
- **Compiler:** [SWC (Speedy Web Compiler)](https://swc.rs/) - Used for fast TypeScript and JavaScript compilation.
- **Task Runner:** [Yarn](https://yarnpkg.com/) - Package management and script execution.

## Styling and UI
- **CSS Preprocessor:** [Sass (SCSS)](https://sass-lang.com/) - For organized, modular, and maintainable styling.
- **UI Components:** Custom React components styled with modern CSS principles.
- **Notifications:** [Toastr](https://github.com/CodeSeven/toastr) - For non-intrusive user alerts and feedback.

## Quality Assurance
- **Testing Framework:** [Jest](https://jestjs.io/) - Used for unit and integration testing of extension logic.
- **Linting:** [ESLint](https://eslint.org/) - Ensures code quality and adherence to project conventions.
- **Formatting:** [Prettier](https://prettier.io/) - Maintains consistent code style across the project.

## Other Key Dependencies
- **DOM Manipulation:** [jQuery](https://jquery.com/) - Specifically utilized for efficient interaction with the Mapgenie website's DOM within content scripts.
